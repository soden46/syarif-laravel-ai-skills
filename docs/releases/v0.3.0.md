# v0.3.0 - Family-Gated Sparse Routing

Language: [English](#english) | [Bahasa Indonesia](#bahasa-indonesia)

<a id="english"></a>

## English

v0.3.0 updates Syarif Laravel AI Skills with smarter sparse routing, automatic project memory flow, and corrected Codex marketplace package validation. The release preserves the 72 canonical Laravel skills and keeps specialist activation sparse: 0, 1, or 2 specialists per task.

## Highlights

- New production routing policy: `family_gated_sparse_routing`.
- Family-gated primary specialist selection.
- Improved support specialist compatibility.
- Reduced unnecessary activation.
- Maximum 0-2 specialists per task remains unchanged.
- Memory preflight behaves as conditional infrastructure.
- `memory-management` does not consume specialist slots.
- Sparse relevant recall with graceful MCP/CLI fallback.
- Durable checkpointing only when useful.
- Codex marketplace validation now counts the actual plugin package surface.

## Benchmark Evidence

Routing heldout showed improved routing accuracy while preserving sparse activation:

| metric | old sparse routing | new routing |
|---|---:|---:|
| mode accuracy | 56.3% | 83.3% |
| primary family | 36.1% | 72.2% |
| primary skill | 30.6% | 69.4% |
| support precision | 45.5% | 100% |
| support recall | 83.3% | 91.7% |
| overactivation | 37.5% | 14.6% |
| avg specialists | 1.313 | 1.125 |
| utility | 0.574 | 0.800 |

Fresh capability benchmark:

| mode | capability |
|---|---:|
| baseline | 58.9% |
| old policy49 | 57.3% |
| new routing | 58.3% |

New routing was non-inferior to baseline in the fresh capability benchmark, measured at -0.5 pp versus baseline and +1.0 pp versus policy49. Promotion gate: PASS.

Token-efficiency benchmark:

| mode | capability |
|---|---:|
| baseline | 60.8% |
| corrected load_all | 59.2% |
| old policy49 | 52.5% |
| new routing | 62.5% |

Candidate B token-efficiency gate: PASS.

This release does not claim strong capability superiority. The public conclusion is that the new routing improved routing accuracy, preserved sparse activation, remained non-inferior in fresh capability validation, and passed the Candidate B token-efficiency gate.

## Packaging Fix

Codex marketplace file-count validation now counts the actual plugin package surface instead of the entire tracked repository. The guard remains 128 files.

Current package surface: 94 files.

All 72 skills are preserved.

## Validation

Verified during release prep with:

```bash
npm run validate
npm run sync
node scripts/validate-production-routing-policy.mjs
node scripts/validate-skills.mjs --memory-flow-only
npx skills add . --list
git diff --check
```
