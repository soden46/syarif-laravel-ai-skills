# v0.2.0 - Sparse Activation And Routing Improvements

Language: [English](#english) | [Bahasa Indonesia](#bahasa-indonesia)

<a id="english"></a>

## English

v0.2.0 updates Syarif Laravel AI Skills with a more selective orchestration path for Laravel/PHP work. The release keeps the 72 existing specialist skills and adds sparse specialist activation so agents can load no specialist, one primary specialist, or a primary plus supporting specialist based on the task.

## Highlights

- Sparse specialist activation with 0/1/2 specialist loading.
- Improved specialist routing and orchestration for primary and supporting context.
- Strict numeric JSON-schema router output contract for activation signals.
- Router schema validation with one schema-only retry.
- Safer checkpoint/resume behavior in benchmark and regression tooling.
- Explicit truncation and runaway-generation handling.
- Stronger benchmark/regression validation artifacts.
- Existing 72 specialist skills preserved.

## Benchmark Summary

Internal V4 / V4.3.2 validation selected the frozen `policy_49` configuration. Canonical aggregate results tied baseline and V3. The final held-out evaluation placed V4 slightly above V3 by one assertion.

This release does not claim strong V4 superiority over V3. The public conclusion is that the sparse activation architecture passed the final promotion gate while preserving the existing skill catalog.

## Validation

Verified before release prep with:

```bash
npm run validate
npm run list
python validate-v4-implementation.py
```

Additional static benchmark runner, validator, and grader self-tests passed without provider or judge calls during pre-commit audit.

## Updating Codex Memory

After updating the skills, refresh the active Codex memory MCP entry so it points at the latest globally installed skill files:

```powershell
npx skills add soden46/syarif-laravel-ai-skills -g -a codex -s "*" -y

$SkillsRoot = "$env:USERPROFILE\.agents\skills"
$MemoryRoot = "$env:USERPROFILE\.ai-memory"

codex mcp remove syarif-memory-management
codex mcp add syarif-memory-management --env AI_MEMORY_ROOT=$MemoryRoot -- node "$SkillsRoot\memory-management\scripts\mcp-server.mjs"
codex mcp list
```

The final list should show `syarif-memory-management` as `enabled`.
